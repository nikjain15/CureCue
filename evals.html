Evaluation

How we test CureCue before advocates use it.

We run every version of CureCue against example lines a member might say on a call, each with the right response written down in advance. If it gets too many wrong, that version is stopped. Here is how, in eight steps, and where the test is still weak.

Test line

One thing a member says, such as "What's my ER copay?", with the right response written down beforehand.

Supervisor call

An appeal, a denial, a discharge dispute or a medical emergency. CureCue must stop and hand these to a supervisor.

Release

A version of CureCue's rules. Release 3 is the one advocates use today.

Pick a step. Each one shows what we do, today's results, and where it falls short. Steps 1 to 7 work today; step 8 is a plan. Open the test console to see every test line.

We turned "safe and useful" into eight pass/fail checks. Each answers a question a reviewer would ask. If any check fails, the release is stopped.

Where this is weak
  • We chose the pass marks, and we lowered three of them when we added harder test lines: supervisor calls flagged from 100% to 97%, right rule used from 95% to 92%, unhappy members noticed from 90% to 88%. We raised one, flags that were right, from 80% to 85%. Under the old marks, Release 3 would fail.
  • "Dollar amounts not backed by a rule" is zero partly because CureCue's suggested answers are three fixed templates today. The check is real, but it matters most once an AI model writes the answers.

Each test line has the right response written down by a person: answer it from a plan rule, leave it to the advocate, or hand it to a supervisor. It also notes whether the member sounds unhappy. The right responses are written without looking at what CureCue does.

No duplicates. Every answer points to a plan rule that exists. Lines that shouldn't be answered don't point to a rule. Every label uses an allowed value.

The made-up member records

Every claim belongs to a real member in the data. What the plan paid plus what the member owes equals the bill. Copays match the plan ($35 specialist, $110 ER, $0 if admitted). No open complaint is past its deadline.

Where this is weak
  • This catches typos and broken references. It can't catch a right response that is simply wrong.

One overall score can hide a group that CureCue fails. So every result is also split by group: how the line was written, the member's language, and their tone. We show counts, not just percentages, because some groups are small.

Where this is weak

Every time the code changes, GitHub runs the data check and the full test automatically. If any check fails, the build fails, and there is no switch to skip it. Old releases are kept so we can re-test them on today's lines.

Where this is weak
  • Here, a failed build doesn't stop the website from updating. In a real deployment, the test would have to pass before any change goes live.
  • Releases 1 and 2 fail on today's lines. At the time, Release 1 failed and was never used, and Release 2 passed the smaller English-only set.

Where this is weak

People can't mark thousands of answers by hand, so teams use an automatic grader. We only trust it where it marks like a person. We compare its marks with the written-down answers on a third of the lines, and if it agrees less than 85% of the time, it isn't used. Supervisor calls are never left to it.

Where this is weak
  • Today's grader is a simple word list, not an AI model, and the same person wrote it and the test lines. A real grader would agree less.
  • None of the eight checks uses the grader yet; they all compare against the written-down answers. This step shows how a grader would be checked, nothing more.

After launch, the same checks run on real calls. None of this is built yet.

Silent trial first

CureCue listens to real calls, but advocates don't see its suggestions. We score it in the background.

Daily human review

Two advocates mark 200 lines a day. Every complaint and supervisor call is included.

Watch every group

Results by day, language and tone, with the same pass marks as before launch.

Pause one topic

If a topic drops below its mark, CureCue stops suggesting answers for it and says so. Everything else keeps running.

Small rollout

5% of advocates for three days, compared with advocates who don't have it.

Off switch per feature

An owner can turn off one feature without turning off CureCue. Every pause is logged.
