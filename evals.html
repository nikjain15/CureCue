Gates

Each metric answers one question a reviewer asks. The gate is the number that stops a release. Thresholds are set where a production system can pass them, not at perfection: a 1.00 on every row is a toy.

Figures off the cited path is zero by construction, not by luck: a draft can only contain numbers read from nodes on its path, and the check runs in CI on every change. Abstention and note omission are reported, not gated, until shadow-mode data sets the band.

Open misses

Each one is a turn a person labelled, what the rules did instead, and why. They stay listed until a release fixes them.

Golden set

Labelled by intent, not by what the rules output.

Every turn carries a verdict, a clause when there is an answer, a dissatisfaction flag, and the strata it belongs to. A hard set, written from the shapes that fail in production, keeps the misses honest. The two-labeller subset is simulated in the prototype; in production two advocates relabel a daily sample.

Release history

Re-scored on today's set: two releases fail, one ships.

The eval runs on every push. A missed gate fails the build; no override flag exists. Release 2 passed CI against the English-only set it was built on; it fails once Spanish and interpreter calls are labelled. When the hard set was added, the bars were reset to defensible ranges (escalation recall 0.97, citation 0.92, dissatisfaction 0.88, precision raised to 0.85), and every remaining miss is listed.

The judge

Used only where it agrees with the labels.

The prototype's judge is a stand-in lexicon scorer, not a model; a model judge would get the same eval. On a held-out slice its agreement is measured per metric; under 0.85 it is refused, and the refusal is printed. Escalation is never given to a judge.

Five rules

What the framework is built on.

Labels share no code with the engine

An eval that reuses the engine's logic can only agree with it.

Score the corpus before the engine

Every clause id exists, every claim adds up, every clock computes. Generated data reads as real until someone computes a ratio.

Gates, not scores

Each metric has a threshold and a consequence. A missed gate fails the build.

The judge is validated or refused

Agreement with the labels on a held-out slice decides whether it may feed a gate.

A number is a number per slice

An average hides exactly the members a fairness principle exists for.

Live, designed

After shadow mode, the same gates on real calls.

Shadow first

Live calls, no advocate sees a cue. Same metrics against labels from the daily sample.

Daily sample

200 turns relabelled by two advocates. Every grievance or escalation is sampled by rule.

Drift by slice

Recall by day, plan, language path and register. The same gap gate as offline.

Pause rule per topic

A topic under its gate stops drafting; the advocate sees "assist paused". The product keeps running.

Canary

5% of advocates, three days, against control on recall, abstention, note omissions and handle time.

Kill switch per skill

An owner stops one behaviour without stopping the product. The pause is itself logged.
